Entry for the make.fun bounty
[The Vacuum's Alibi: One Line, 200 Characters](https://make.fun/c/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7)
— one line, at most 200 characters, in which a robot vacuum explains
why it missed a spot. A house judge compares the lines two at a time
and picks the funniest, weighing deadpan robot voice, surprise, and
tightness.

## The line

> My sensors insist that spot is a sleeping dog, so I have tiptoed around it for six months. It is a rug.

## How it works

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`, then re-reads the file and verifies it is a single
line of 1–200 characters before exiting.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
